## Recursos
- [Logo SVG](logo.svg): logotipo geométrico de zorro.
- [Banner SVG](banner.svg): cabecera panorámica para el perfil.
- Los SVG son editables y escalables.
- No se deben publicar números de estrellas, colaboradores, forks ni repositorios sin comprobarlos.

## Uso recomendado
Conservar espacio suficiente alrededor del emblema, usar tipografía sans serif de alta legibilidad y mantener contraste entre texto y fondo. No presentar proyectos privados como repositorios públicos.

El README de la organización está en `profile/README.md`. Para mostrar el logo como avatar de la organización, un administrador debe subir el recurso en la configuración del perfil de GitHub.
